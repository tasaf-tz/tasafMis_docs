Login
^^^^^

To access the TASAF Social Protection Registry system, users must have a valid Login Name and Password. These credentials are created and provided by the System Administrator or another authorized administrator responsible for user management.

Open a web browser and type the URL of the TASAF MIS / Social Protection Registry system in the browser address bar. The login page will be displayed (:numref:`login_interface`).

.. _image1:
.. figure:: /img/user_manual/login/login_interface.png
  :align: center

  `User Login`

Enter the provided Login Name and Password, then click the **Login** button. If the credentials are correct, the system will redirect the user to the Home Page (:numref:`home`).

.. _home_page:
.. figure:: /img/user_manual/login/home.png
  :align: center

  `Home Page`

After login, the system displays the menu based on the user’s assigned role and access rights. Users will only see the menus and functions that they are authorized to access.

For the Social Protection Registry, the available menus may include registry-related functions such as household registration, individual registry, targeting, enrollment, verification, updates, and reports, depending on the role assigned to the user.

The main menu is displayed on the left side of the Home Page. Clicking on a menu heading opens the related sub-menu and allows the user to navigate to the required function.

At the top section of the system, the user can view information related to the current login session. This may include the Login Name, assigned role or roles, and the administrative area to which the user has access, such as region, council, ward, village, or other assigned operational area.

User accounts and role assignments are managed through the **Users Administration** page. System roles and permissions are managed through the **User Roles Administration** page. These administration functions are only available to authorized system administrators.
